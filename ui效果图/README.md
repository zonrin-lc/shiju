## 一、这一版改了什么（与原型的距离）

上一版（深色卡片）被判定为「跟没设计一样」，根因是**只在原型骨架上做抛光**。
这一版**换载体**，不是换皮肤：

| | 原型 v1.6.8 | 本方向 |
|---|---|---|
| 底色 | 深褐近黑 `#17140f` | **米黄绢帛** `#eae0c6`（真实生成纹理） |
| 文字方向 | 全横排 | **竖排为主**（`writing-mode: vertical-rl`），自右向左起读 |
| 结构线 | 无 / 仅分隔线 | **朱砂界行**（帛书竖格）贯穿全屏 |
| 剧本卡 | 竖条卡 + 底部文字 | **简牍**：编绳穿孔 + 竖排局名写在简左侧 |
| 主 CTA | 圆角矩形按钮 | **朱文方印**（双边、略斜如手钤） |
| 偏离度 | 顶栏 5px 细横条 | **界格染红**：帛上的竖格被朱砂逐格染红 |
| 结局史传 | 横排段落 | **竖排多列**，自右向左（结局页招牌） |

**配色从深翻到浅**是幅度最大的一步——一眼就与原型不同族。

## 二、四个设计决定

### 1. 载体 = 帛书 / 简牍
秦汉人真正写字的地方。文字游戏就该长在帛上。
底纹不是 CSS 画的，是 `gen_silk.py` **逐像素生成**的：经纬织纹（3px 平纹）+ 低频染色不匀 + 短纤维 + 霉斑(foxing) + 四边做旧，1024² 可平铺，种子固定可复现。

### 2. 竖排是纲，不是装饰
`writing-mode: vertical-rl` + `text-orientation: upright`。
题名、局名、难度名、史传全部直立书写，自右向左起读。
**长段落仍横排**——竖排 80 字长文在手机上不可读，这个取舍是有意的。
`src/silk.css` 的 `.v` 是竖排工具类（**注意：不要拿它当普通 class 名，会和排版冲突**）。

### 3. 界行 = 偏离度的外化
帛书与简牍上用朱砂画的竖格线（界格）。本作把它变成机制的可视化：
**偏离度越高，被朱砂染红的格越多**。「你在改写史书的格子」。

### 4. 印即按钮
交互控件用朱文方印，不用圆角矩形。`seal-btn` 已含双边内框与手钤的轻微旋转。

## 四、已知取舍与待定

1. **竖排 vs 横排的分界**：目前「短文字竖排、长段落横排」。若要更彻底（事件叙事也竖排），需先做真机可读性验证——建议在 5-4 章那种长叙事的回合页上试。
2. **立绘与浅底的冲突**：`char_*.png` 原为深底设计，放在浅帛上偏重。可选：加深色底衬托 / 换成线描版立绘 / 保留现状。
3. **深色模式**：本方向是纯浅底，硬核模式的"隐藏数值"仍可用同一套（少显示数字即可），无需另做暗色。
4. **资产**：本版**未引入新美术**，仅复用 `assets/`（`char_*.png` / `seals/` / `icons/`）与新生成的 `tex_silk.png`。
